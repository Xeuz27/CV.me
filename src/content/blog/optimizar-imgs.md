## como afecta al seo, al rendimiento y a las conversiones no tener imagenes optimizadas

para empezar una de las primeras cosas por las cuales la optimizacion de imagenes es no solo una buena practica si no tambien fundamental y necesario es por que al tener imagenes que sean excesivamente pesadas los tiempos de carga de el sitio web en general suben y esto afecta negativamente al rendimiento, lo cual afecta la experiencia del usuario, lo cual afecta tambien indirectamente al SEO, lo cual a su vez tambien afecta las conversiones.

> Las páginas que tardan en cargar, tienen una tasa de abandono cerca del 57%, casi del 100% en los dispositivos móviles (un 97% más o menos).

> Si tu sitio web no carga lo suficientemente rápido, los clientes potenciales se irán antes de ver tu oferta.

## ¿Qué herramientas se pueden usar para comprimir imágenes sin comprometer la calidad?

hablando de recursos para optimizar imagenes, hay muchos y de varios tipos por ejemplo, servicios web, aplicaciones o hasta APIs

### imagecompressor:

La herramienta analiza automáticamente cada archivo y selecciona configuraciones de compresión óptimas. Una vez completado el procesamiento, puedes guardar el resultado inmediatamente o usar la vista de comparación para ajustar la calidad con el control deslizante. Cada imagen puede ajustarse individualmente antes de guardar.

para usar imagecompressor haz click aqui: <a title="image compressor" href="https://imagecompressor.com/es/" target="_blank" rel="nofollow noopener">ImageCompressor</a>

### Squoosh:

squoosh es una aplicacion web para compresion de imagenes de arrastrar y soltar, es de Google y es de codigo abierto, es facil de usar y ofrece varias opciones para personalizar la optimizacion de tus imagenes como, redimensionar el tamaño de tu imagen, reducir la paleta de colores ( que personalmente no les recomiendo usar ) o cambiar el formato de la imagen y la calidad de la conversion es decir si la optimizacion es exhaustiva o ligera

para usar haz click aqui:
<a title="Squoosh App" href="https://squoosh.app/" target="_blank" rel="nofollow noopener">Squoosh</a>

### iloveimg

iloveimg tambien es bastante util dejandote comprimir tus imagenes en bloque, solo entras seleccionas tus imagenes y le das a comprimir y las tienes listas para descargar en un .zip, util si de ante mano tienes muchas imagenes por optimizar

para usar haz click aqui: <a title="ILoveImg" href="https://www.iloveimg.com/es/comprimir-imagen" target="_blank" rel="nofollow noopener">ILoveImg</a>

### ImageOptim

si estas en mac y quieres descargar una app antes de hacerlo todo por la web, imageOptim te da esa posibilidad.

para descargar haz click aqui: <a title="imageOptim" href="https://imageoptim.com/mac" target="_blank" rel="nofollow noopener">imageOptim</a>

### Tinypng

como ultima herramienta pero no menos importante tenemos a TinyPNG, igualmente dejandote optimizar todas tus imagenes en bloque, y permitiendote descargarlas luego de un click en formato .zip

para usar haz click aqui:

## Bonus: crear tu propia API de optimización de imágenes

y si ya llegaste hasta aquí y sientes que aún puedes hacer algo más para optimizar las imágenes en tu sitio, estás en lo correcto.

hacer esto de forma manual está bien para casos puntuales, pero en aplicaciones reales lo común es automatizar este proceso, normalmente cuando las imágenes se suben al servidor.

de esta forma, guardas una versión optimizada desde el inicio y evitas tener que procesarlas cada vez que un usuario las solicita.

para esto necesitas un poco de lógica en el backend. por ejemplo, usando `sharp` en Node:

```ts
import sharp from 'sharp';

export async function POST({ request }) {
	try {
		const formData = await request.formData();
		const file = formData.get('file');

		if (!(file instanceof Blob)) {
			return new Response(JSON.stringify({ error: 'archivo inválido' }), {
				status: 400,
				headers: { 'Content-Type': 'application/json' }
			});
		}

		const buffer = Buffer.from(await file.arrayBuffer());

		const optimized = await sharp(buffer)
			.resize({ width: 1200 }) // opcional
			.webp({ quality: 70 })
			.toBuffer();

		await saveToDb(optimized, 'imagen-1'); // aqui guardas con el metodo pertinente
		// al servicio o DB que estes usando en tu app

		return new Response(JSON.stringify({ message: 'imagen optimizada correctamente' }), {
			status: 200,
			headers: { 'Content-Type': 'application/json' }
		});
	} catch (error) {
		return new Response(JSON.stringify({ error: 'error al procesar la imagen' }), {
			status: 500,
			headers: { 'Content-Type': 'application/json' }
		});
	}
}
```

Al final, optimizar imágenes no es solo una buena práctica, es una de las formas más simples de mejorar el rendimiento de tu sitio.

menos peso, más velocidad, mejor experiencia.

porque no importa qué tan bien se vea tu sitio, si tarda demasiado en cargar, los usuarios simplemente no se quedan.

ya sea usando herramientas como Squoosh o automatizando el proceso en tu backend, lo importante es no dejar este paso de lado.
